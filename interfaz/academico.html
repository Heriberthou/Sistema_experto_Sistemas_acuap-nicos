Qué puedes explorar

El sistema usa respuestas Sí (V), No (F) y Desconozco (D). Una respuesta desconocida nunca se interpreta como negativa.

Cómo razona

Python evalúa las reglas editables con lógica trivaluada de Kleene fuerte. Hacia adelante acumula resultados; hacia atrás busca las premisas necesarias para una meta.

Las reglas se consideran en orden de identificador. Se conservan las justificaciones compatibles y se detienen las derivaciones afectadas por contradicciones.

Lo que queda fuera

No conecta sensores, controla equipos, prescribe sustancias ni establece diagnósticos veterinarios o causas definitivas de mortalidad. No calcula probabilidades ni ha sido validado en instalaciones reales.

Tus respuestas

La consulta vive en la memoria de esta pestaña y se envía al servidor local para calcular resultados. No se guarda en una base de datos ni en almacenamiento del navegador. Reiniciar o recargar elimina la consulta.
